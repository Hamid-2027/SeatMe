# 🎨 Design Theme: Colors & Fonts

This document outlines the visual design standards used in the intro screens for the Travel Guide & Ticket Booking App.

---

## 🖋️ Fonts

| Font Name   | Use Case                | Notes                            |
|-------------|--------------------------|----------------------------------|
| SF Pro      | Primary UI font (iOS)    | Clean, modern, Apple system font |
| Roboto      | Primary UI font (Android)| Widely supported, clean and legible |
| Helvetica Neue | Fallback              | Elegant and neutral              |
| Arial       | Fallback                 | System-safe sans-serif font      |

> All fonts are selected for readability, modern appearance, and compatibility across platforms.

---

## 🎨 Color Palette

| Name             | Hex Code   | Usage Example                       |
|------------------|------------|-------------------------------------|
| Primary Color     | `#F25F4C` | Highlight buttons, icons, accents   |
| Accent Blue       | `#007AFF` | Secondary CTA, links                |
| Background White  | `#FFFFFF` | Main background                     |
| Text Primary      | `#1C1C1E` | Headlines, main labels              |
| Text Secondary    | `#8E8E93` | Captions, subtitles, descriptions   |
| Light Gray        | `#F2F2F7` | Dividers, card backgrounds          |

---

## 🧩 UI Style Notes

- **Rounded corners** for cards and buttons (8–12px radius)
- **Drop shadows** for elevation effects
- **Minimalist layout** with plenty of white space
- **Flat iconography** for a clean modern aesthetic

---

These values ensure a cohesive, user-friendly experience and match the visual tone of top-tier travel apps.
